# Music Note Transposer

**Note Transposer** is an intelligent web application designed for musicians, to bridge the gap between sheet music images and playable transposed notes. Powered by **Gemini 1.5 Flash**, it converts images into digital notation and transposes them for different instruments.

## Features
* **AI Image Analysis:** Convert photos of sheet music into digital note data using Google Gemini AI.
* **Smart Transposition:** Instantly transpose notes between C, Bb, Eb, and F instruments
* **Sheet Music Visualization:** Renders professional-looking musical scores using ABCJS.
* **Measure-Based Layout:** Automatically organizes notes into 4/4 measures with 4 measures per line.
* **Interactive Editor:** Manually edit AI-generated notes to fine-tune your performance.

## Tech Stack
* **Streamlit:** Web Interface
* **Google GenAI:** Computer Vision & AI Logic
* **ABCJS:** Musical Notation Rendering
* **Python:** Backend Logic
